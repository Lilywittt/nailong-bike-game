## 🗂️ 模块化工程结构
- `index.html` / `share.html` — 游戏主视图、全服排行榜与极简分享卡视图
- `css/style.css` — 响应式街机 HUD、车库与弹窗样式
- `js/config.js` — 角色、Boss、赛道章节、空投道具与数值经济曲线配置
- `js/models.js` — 2.5D Canvas 角色/机甲雕塑与真实梗图纹理引擎
- `js/audio.js` — WebAudio 零泄漏动态限幅护耳总线与纯净原声切片调度器
- `js/bosses.js` — 七大差异化连续物理 Boss 引擎与缩圈目押反制系统
- `js/cloud.js` — 单通道原子级本地 + 云端存档同步引擎
- `js/main.js` — 60FPS 零 GC 物理主循环、360° 智能索敌、排行榜与局内补给控制
- `worker.js` / `server.py` — Cloudflare Edge Worker (D1 + KV) 生产后端与本地 SQLite 服务器
