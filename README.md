# 鹈鹕测试大乱斗 (Pelican Test Brawl)

网页端街机横版动作跑酷与双人联机竞速游戏，支持电脑与手机浏览器直接游玩。  
在线地址：[https://nailong.openwaifu-agent.uk](https://nailong.openwaifu-agent.uk)

![鹈鹕测试大乱斗二维码分享卡](./assets/promo_card.svg)

## 主要玩法与功能
- **四键基础操作与五名可选角色**：左侧为「起跳」与「超级冲刺」（按住持续冲撞破障并推退首领，松手即停），右侧为无冷却普通攻击「铁山靠」与各角色主动技能：
  - **大头奶龙** (`78 HP`)：持续喷火攻击与空中悬浮推进（支持自动转向攻击后方首领）
  - **狂笑奶蛙** (`90 HP`)：360° 旋转长舌范围电击清场
  - **中分 ikun** (`102 HP`)：投掷高弹跳篮球连续弹射攻击
  - **背带鹈鹕** (`118 HP`)：张嘴吸入前方小怪并转化为远程炮弹发射
  - **哈基米猫** (`136 HP`)：四段空中连跳与投掷圆头耄耋攻击
- **七个章节首领与反制机制**：
  1. **曼波**：高弧弹跳（可踩头或近战拍回）与舞台音浪金麦反击
  2. **大狗嚼**：后方追击扑咬（可跳跃躲避或近战击退）与肉骨引诱撞击炸药桶
  3. **叮咚鸡**：低空空投路障与俯冲弹反眩晕
  4. **黄金马桶蛙皇**：涨水浮桥拉栓放水与贴地长舌反制
  5. **两年半机甲坤王**：击地传球抢断扣篮与近身冲撞反制
  6. **双涡轮机甲猫**：抛物线飞扑反拍与毛线球击回缠绕
  7. **暗黑熔岩暴龙王**：断路磁浮桥电击与熔岩陨石击回
- **单人无尽闯关**：随里程递增难度，包含空投支援道具、云端超级奖励关、每 500m 存档点、角色升级、道具强化与绿豆永久天赋。
- **3.5km 双人实时竞速（PvP）**：支持快速匹配、好友房号建房/进房、人机对战、双车弹力绳牵引、右上角对手实时小窗、冲线后观战、房间内直接换角色及 14 种赛道道具对抗。
- **排行榜与云端存档**：支持全服单命里程排行榜（上限 999,999m）、账号密码跨端云同步（保留最近 12 份历史存档备份）及对局中途刷新网页恢复进度。

## 最近更新（v9.1 · 2026-11-26）

完整更新记录见 [CHANGELOG.md](./CHANGELOG.md)。

### v9.1 高空关卡与机关重构
- **移除全部空中电锯**：取消空中巡航电锯，滚锯仅保留在地面。
- **新增空中大摆锤、加速环与弹跳气球**：单人闯关与双人竞速赛段加入带轨迹提示的巨型大摆锤（无法用普通攻击打碎，需看准空隙或从上方越过）、蓝/金涡轮加速环（穿环提速并恢复空中连跳）以及高空弹跳气球。

### v9.0 功能与问题修复（2026-11-25）
- **顶栏教程整合**：车库顶栏合并「教程」入口，包含单人教学、双人 14 种道具教学与账号防丢档说明。
- **双人道具教学重做**：扩充为 10 小节覆盖全部 14 种道具，改为手动点击「再练一次」或「进入下一节」，不再自动跳关。
- **冲线后观战与原房换人**：双人模式先冲线后支持实时观战落后对手；结算页与候车室支持直接切换角色，无需退房回车库。
- **刷新网页恢复对局**：双人联机与单人闯关中途刷新网页后，重新进入可自动重连原房间或恢复单人当前进度。
- **界面与操作优化**：双人模式道具栏移至右下角普通攻击按钮正上方垂直排列；车库顶栏改为固定单行布局，避免挤压首屏主按钮；结算与暂停弹窗适配手机横屏双栏布局与滑动。
- **单人模式数值与空战调整**（不影响双人竞速）：上调单人最高基础移速，「超级冲刺」设为正常移速 5.0 倍，「氮气冲刺」设为正常移速 2.0 倍；延长「迫击猫」持续时间并改为双发制导榴弹；各章节增加多高度空中敌人与长时间滞空拦截机制。

## 工程目录说明
- `index.html` / `share.html` — 主页面、弹窗结构与分享页
- `css/style.css` — 界面布局、HUD 与横竖屏自适应样式
- `js/config.js` — 角色、首领、章节、道具与数值配置
- `js/models.js` — Canvas 角色、载具与特效绘制
- `js/scenery.js` — 地形、背景与障碍物绘制
- `js/audio.js` — WebAudio 音效合成与音频切片播放控制
- `js/bosses.js` — 首领行为状态机与反制判定
- `js/cloud.js` — 本地与云端存档同步模块
- `js/party.js` — 双人联机房间、同步、道具与竞速逻辑
- `js/main.js` — 游戏主循环、单人关卡生成、碰撞与结算控制
- `worker.js` / `party_worker.js` / `server.py` — Cloudflare Worker（D1 + KV）线上后端与本地 SQLite 调试服务
